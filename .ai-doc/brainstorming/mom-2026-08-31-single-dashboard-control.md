## Agenda & Keputusan

### 1. Framework Frontend & Server
- **Keputusan:** ✅ **Svelte / SvelteKit Stack** dengan `@sveltejs/adapter-node`.
- **Alasan:** Zero Virtual DOM overhead, compile-time reactivity, bundle ultra-kecil (~30KB), dan satu server Node.js terpadu (UI + Backend API).

### 2. Mekanisme Realtime Streaming
- **Keputusan:** ✅ **Server-Sent Events (SSE)** via endpoint `/api/metrics/stream`.
- **Alasan:** Native browser `EventSource`, auto-reconnect bawaan, zero library tambahan, 100% kompatibel dengan reverse proxy (Nginx).

### 3. Design System: VIP-1 Risograph Broadsheet Dashboard
- **Keputusan:** ✅ Mengadopsi style **Editorial Broadsheet Risograph Print** dengan 4 warna signature:
  * `#FAFAFA` (Canvas / Clean Paper)
  * `#C7EEFF` (Ice Sky Cyan Accent)
  * `#0077C0` (Electric Royal Cyan / Primary Action)
  * `#1D242B` (Deep Charcoal Ink / Hard Borders & Text)
- **Typography:** `Big Shoulders Display` (Display Slabs), `Fraunces` (Serif Body), `JetBrains Mono` (Telemetry & Code).
- **Charts:** ApexCharts dengan Risograph Solid Grid Theme.
