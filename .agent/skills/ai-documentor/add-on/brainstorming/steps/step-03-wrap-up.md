# Step 3: Wrap-Up & Output Generation

> Generate output terdokumentasi: MoM dan Discussion Summary per sub-topik.
> Simpan ke `.ai-doc/brainstorming/`.

---

## Trigger

- User bilang "selesai" atau "cukup"
- Semua sub-topik selesai difasilitasi

---

## Yang Dilakukan Agent

### 1. Review Semua Ide

Tampilkan ringkasan ke user:

```
=== REVIEW SESI ===
Topik: [session_topic]
Area: [area]
Sub-topik: [jumlah]
Total ide: [jumlah]
- Approved: [jumlah]
- Rejected: [jumlah]
- Modified: [jumlah]

Status: Ada yang perlu direview ulang? (y/n)
```

### 2. Konfirmasi Keputusan

Untuk setiap sub-topik, konfirmasi keputusan final:

```
Sub-topik 1: [nama]
  Keputusan: [rata-rata ide yang approved]
  Apakah ada keputusan tambahan? (y/n)
  → Jika ya: catat sebagai [KEPUTUSAN]
```

### 3. Tanya Action Items

```
Apakah ada action items yang perlu dicatat?
  - Task: ...
  - Owner: ...
  - Deadline: ...
```

User bisa menambahkan 0 hingga beberapa action items.

### 4. Generate MoM

Gunakan template: `add-on/brainstorming/template/mom-template.md`

Isi template dengan data sesi:

| Field | Sumber Data |
|---|---|
| `{{date}}` | session_state.session_date |
| `{{start_time}}` - `{{end_time}}` | waktu mulai & selesai |
| `{{session_topic}}` | session_state.session_topic |
| `{{area}}` | session_state.area |
| `{{participants}}` | session_state.participants |
| `{{techniques_used}}` | gabungan teknik dari semua sub-topik |
| `{{topics}}` | session_state.sub_topics |
| `{{action_items}}` | session_state.action_items |
| `{{additional_notes}}` | input user |

**Output path:**
```
.ai-doc/brainstorming/mom-{YYYY-MM-DD}-{topic-slug}.md
```

Topic slug: lowercase, gunakan `-` sebagai separator, maksimal 5 kata.

### 5. Generate Discussion Summary per Sub-Topik

Untuk setiap sub-topik, gunakan template: `add-on/brainstorming/template/discussion-template.md`

Isi template dengan data per sub-topik:

| Field | Sumber Data |
|---|---|
| `{{session_topic}}` | session_state.session_topic |
| `{{area}}` | session_state.area |
| `{{topic}}` | nama sub-topik |
| `{{date}}` | session_state.session_date |
| `{{category}}` | kategori teknik sub-topik |
| `{{technique}}` | teknik yang dipakai sub-topik |
| `{{participants}}` | session_state.participants |
| `{{idea_count}}` | jumlah ide di sub-topik |
| `{{context}}` | konteks sub-topik |
| `{{ideas}}` | daftar ide (approved + modified) |
| `{{discussions}}` | hasil diskusi |
| `{{final_decisions}}` | keputusan final |
| `{{next_steps}}` | action items terkait |
| `{{references}}` | referensi |

**Output path per sub-topik:**
```
.ai-doc/brainstorming/discussion-{subtopic-slug}-{YYYY-MM-DD}.md
```

Subtopic slug: lowercase, gunakan `-` sebagai separator, maksimal 5 kata.

### 6. Tampilkan Ringkasan ke User

```
=== BRAINSTORMING SELESAI ===

Output generated:
├── .ai-doc/brainstorming/mom-{date}-{topic-slug}.md
└── .ai-doc/brainstorming/discussion-{subtopic-slug}-{date}.md
    (1 file per sub-topik)

Total ide approved: [jumlah]
Total ide rejected: [jumlah]
Action items: [jumlah]

Sesi siap digunakan untuk langkah dokumentasi selanjutnya.
Kembali ke core AI Documentor.
```

---

## Aturan

### Output

- **JANGAN** buat output jika user tidak menginginkannya.
- **JANGAN** simpan file di luar `.ai-doc/brainstorming/`.
- **HARUS** gunakan template — jangan generate format bebas.
- **HARUS** cantumkan footer: `*Generated by AI Documentor — Brainstorming Add-On*`.

### Data

- Hanya ide dengan status **approved** atau **modified** yang masuk ke output.
- Ide **rejected** tetap tercatat di log sesi, tidak di output.
- Jika sub-topik tidak memiliki ide approved, tulis: `Tidak ada ide yang disetujui untuk sub-topik ini.`

### Return Control

Setelah selesai:
1. Output path dicatat ke session state.
2. Kontrol dikembalikan ke **core AI Documentor** (SKILL.md).
3. User bisa melanjutkan dengan workflow dokumentasi biasa.
