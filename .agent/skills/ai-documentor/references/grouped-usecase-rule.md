# Grouped Use Case Document Rule

- `Dokumentasi-Komponen-Usecase.md` HARUS mengikuti section standar: `1. Ringkasan`, `2. Diagram Use Case Tergrup`, `3. Daftar Use Case per Komponen`, `4. Catatan Pengelompokan & Sinkronisasi DCD`
- Untuk dokumen penuh, gunakan `template/grouped-usecase-document-template.md` sebagai baseline utama
- Diagram di section 2 HARUS mengikuti `template/usecase-diagram-template.md`
- Nama komponen dan nama use case HARUS konsisten antara diagram, daftar komponen, dan DCD terkait
- Paragraf `Deskripsi` pada tiap komponen harus singkat dan tidak mengulang daftar use case atau ringkasan global
- Gunakan bullet `Implementasi` hanya untuk detail teknis tambahan yang tidak sekadar mengulang nama use case
